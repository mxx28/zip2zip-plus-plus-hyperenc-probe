# Hyper-encoder embedding probe — v0.6.4 (untied, residual)

Single-checkpoint report (`v064`). Analysis runs on the **final vector the model uses** (residual **on**: `E = base_vec[t1] + encoder_out`). Bit-exact encoder re-implementation (max|Δ|=0 vs `model.py`). A shared *ruler* vector is not guaranteed (see ②), so ④ and ⑤ are shown **both** on the raw vector and after ruler removal. Method: see `docs/hyper_probe.md`.

## Data & objects

**Corpus:** Salesforce/wikitext · wikitext-2-raw-v1 [train] — 2,824,489 base tokens. **Hyper-tokens:** consecutive base-token K-grams (K=2/3/4), dropping any window with a special/digit token, deduplicated, keeping the **top-5000 by corpus frequency** per K (frequency only bounds the sample; the encoder is a fixed function of the K ids, so any valid K-tuple probes the same geometry). **Base-token pool** (④ replacement + ② floor): 18,028 unique tokens. Seed 0, ④ averaged over 6 resamples.

## Reading

- **output**: **prefix-sensitive (reads the head)** (change-first/change-last = 17.84× at K=4). Shared-ruler component is at its matched init baseline (cos-with-mean 0.3959 vs init 0.433), i.e. **inherited** from the base-embedding geometry, not created by training.
- **input**: roughly balanced across positions (change-first/change-last = 0.96× at K=4). Shared-ruler component is modest (cos-with-mean 0.4295), above its matched init baseline (0.152) — a mild, **partly training-induced** shared direction, but far from a full collapse.

## ② Shared ruler (does one common vector dominate every hyper-token?)

cos-with-mean → 1 means all hyper-tokens are nearly the same vector. To ask whether training *created* a shared direction, compare against the model's **matched step-0 init** — the value before any training: for this residual run that is **E0 = e(t1)** (`init (matched)` column). The `rand-enc` column is always the full-scale random encoder (γ=1); for residual runs it is **not** the matched init and must not be used as the reference. `tok floor` is the ordinary-token anisotropy floor in the same space.
