# Hyper-encoder embedding probe — vx0.6.4.2 (untied, no-residual)

Single-checkpoint report (`vx0642`). Analysis runs on the **final vector the model uses** (residual **off**: `E = encoder_out`). Bit-exact encoder re-implementation (max|Δ|=0 vs `model.py`). A shared *ruler* vector is not guaranteed (see ②), so ④ and ⑤ are shown **both** on the raw vector and after ruler removal. Method: see `docs/hyper_probe.md`.

## Data & objects

**Corpus:** EleutherAI/wikitext_document_level (same WikiText-2-raw text) · wikitext-2-raw-v1 [train] — 2,827,024 base tokens. **Hyper-tokens:** consecutive base-token K-grams (K=2/3/4), dropping any window with a special/digit token, deduplicated, keeping the **top-5000 by corpus frequency** per K (frequency only bounds the sample; the encoder is a fixed function of the K ids, so any valid K-tuple probes the same geometry). **Base-token pool** (④ replacement + ② floor): 18,028 unique tokens. ## Reading

- **output**: **prefix-sensitive (reads the head)** (change-first/change-last = 3.66× at K=4). It also **collapses onto a shared ruler** (cos-with-mean 0.9986, 100% of length), well above the ordinary-token floor (0.213) and random-init (0.639) — a learned, per-merge-uninformative direction.
- **input**: **tail-weighted** (change-first/change-last = 0.37× at K=4). Shared-ruler component is moderate (cos-with-mean 0.7163).
