同一套方法(①原始相似度 ②证明共享标尺 ③减标尺后相似度 ④因果最小对 ⑤嵌套)跑在两个模型上，每个 section 并列，直接看去掉 residual 带来的差异。

对比结论

核心分工在两个模型里都成立：output 认开头（前缀）、input 更均匀、偏后。
去掉 residual 后：output 的前缀主导变弱但仍在（改首/改尾比 9.2× → 3.3×），且露出更清楚的递推衰减；input 从「U 型」变成「向末尾单调递增」。

这说明：v0.5 里 output 极端偏第一个词，一部分是 residual（把 t1 加回去）撑起来的，一部分是 encoder 本身学到的——去掉 residual 后前缀性没消失，只是没那么夸张。而 output 的塌缩（共享标尺 99.7%）与 residual 无关，两模型一样。

OUTPUT

递推衰减：更清楚了。v0.52 出现 0.27>0.12>0.08 的渐降，比 v0.5 的尖峰更像"graded prefix"。

INPUT

逐位置形状：U 型 → 向末尾递增。residual 原本把首位垫高造成 U 型；去掉后露出 encoder 本身偏后的趋势。

因果最小对：几乎不变。改首/改尾比 0.31 vs 0.33——input 行为基本不吃 residual（encoder_out 本来就主导）。

塌缩：都中等(~46%)。input 从不塌缩。

⑦对假设 & 实验的判定（两模型一致）

✓

output = 前缀敏感：两模型都成立。改第一个词的影响始终大于改最后一个(9.2× / 3.3×)。去掉 residual 后还更像"渐降前缀"。

✓

input = 较均匀、偏后：两模型都成立。各位置都用上、末尾略重(比值 <1)，不由单一位置主导；去 residual 后偏后更明显。

!

对 v0.7/hierarchical 的启示不变。output 高度塌缩(99.7%)、且塌缩与 residual 无关——把 hierarchical 装在 output 侧,是在一个表达力没被用满的角色上加复杂度(这也和你观测到的 hierarchical 无明显增益一致)。要试更应放 input 侧，或先查 output 为何塌缩(hyper-token 输出位置少、梯度弱)。
