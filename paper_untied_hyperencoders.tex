\section{Untied Hyper-Encoders Learn Role-Specific Compositional Structure}
\label{sec:untied hyper-encoders}

Untying is not merely an architectural convenience: it allows the input and
output hyper-encoders to learn different composition rules suited to their
respective roles. The output encoder produces strongly \emph{prefix-preserving}
representations, whereas the input encoder \emph{integrates} information across
the whole span. Consistent with this, tying or sharing the two hyper-encoders
degrades downstream quality---most visibly on free-form generation---because a
single shared map cannot simultaneously satisfy both roles. Crucially, the
structure we uncover is learned: it is absent from the base embedding tables from
which the constituent vectors are read.

\paragraph{Setup.}
A hyper-token $H$ is a merge of $K$ base tokens $[t_1,\dots,t_K]$
($K\!=\!2,3,4$), embedded by two encoders: the \emph{input} encoder reads the
token-embedding matrix $\mathbf{W}_{\text{in}}$ and produces the vector injected
into the decoder stream in place of $H$; the \emph{output} encoder reads the
unembedding matrix $\mathbf{W}_{\text{out}}$ and produces the row that scores
emitting $H$. After training both encoders are frozen, so $E(H)$ is a
\emph{deterministic function of the $K$ base-token ids alone}; any valid
$K$-tuple therefore probes the same learned geometry, and no access to the
model's runtime codebook is required. We draw hyper-tokens from
WikiText-2-raw-v1---every consecutive base-token $K$-gram, excluding windows with
a special or digit token, deduplicated, keeping the top $N\!=\!5000$ per $K$ by
corpus frequency (frequency only bounds the sample). As a control, we exploit the
fact that a BPE base token is \emph{itself} an ordered composition: greedy
byte-pair merging gives each vocabulary token a unique decomposition into $K$
real sub-word pieces, each a real token with its own embedding. Running the
identical diagnostics directly on the raw matrices $\mathbf{W}_{\text{in}}$ and
$\mathbf{W}_{\text{out}}$ (no encoder) isolates whether a positional tendency is
\emph{created} by the hyper-encoder or merely \emph{inherited} from the embedding
tables. Per the frozen-encoder argument, we report the untied checkpoint
(\texttt{v0.6.4}) against this base-table control.

\paragraph{Diagnostics.}
We use two complementary probes. \emph{(i) Causal minimal pairs:} we replace
exactly one constituent---the \emph{first} versus the \emph{last}---and measure
how far the representation moves. With $H^{\text{first}}$/$H^{\text{last}}$
denoting $H$ with its first / last constituent replaced,
%
\begin{equation}
r_K \;=\;
\frac{\mathbb{E}\!\left[\,1-\cos\!\big(E(H),\,E(H^{\text{first}})\big)\,\right]}
     {\mathbb{E}\!\left[\,1-\cos\!\big(E(H),\,E(H^{\text{last}})\big)\,\right]},
\qquad
\begin{cases}
r_K > 1 & \text{prefix-dominated,}\\
r_K < 1 & \text{tail-weighted.}
\end{cases}
\end{equation}
%
For hyper-tokens the replacement is drawn uniformly from the corpus base-token
pool (averaged over $6$ resamples); for base tokens $H^{\text{first}}$/$H^{\text{last}}$
are real vocabulary tokens sharing the other $K\!-\!1$ pieces. \emph{(ii)
Nested-prefix probe:} we grow a span one token at a time while preserving its
prefix and compare each prefix to the shortest. We write the prefixes
$H_2\!\subset\!H_3\!\subset\!H_4$, where $H_k$ is the merge of the first $k$ base
tokens---e.g.\ for \textit{``It is a dog''}, $H_2{=}[\text{It, is}]$,
$H_3{=}[\text{It, is, a}]$, $H_4{=}[\text{It, is, a, dog}]$---and report
$\cos(H_2,H_3)$ and $\cos(H_2,H_4)$. A high, slowly-decaying similarity means the
representation is anchored to the shared prefix. Since the raw tables hold only
whole tokens, the base control uses three nested real words instead
(\textit{success}\,$\subset$\,\textit{successful}\,$\subset$\,\textit{successfully}).

\subsubsection*{Observations:}

\textbf{1. The output encoder is a prefix / entry-point detector, increasingly so
with span length.}
  Replacing the first constituent moves $E_{\text{out}}(H)$ far more than
  replacing the last, and the asymmetry grows with $K$: $r_K$ rises from $6.2$ at
  $K{=}2$ to $20.9$ at $K{=}4$ (Table~\ref{tab:minimal-pairs}). The nested probe
  shows the same trend from the other side: as the span grows the output
  representation stays high and decays only slightly
  ($\cos(H_2,H_3){=}0.94\!\to\!\cos(H_2,H_4){=}0.88$,
  Table~\ref{tab:nested-prefix}), because the growing spans share a prefix. How
  the model scores emitting a hyper-token is thus governed largely by the head of
  the span.

\textbf{2. The input encoder integrates information across the whole span.}
  Its minimal-pair ratio is near-balanced---mildly tail-weighted for short spans
  ($r_2{=}0.55$) and essentially symmetric by $K{=}4$ ($r_4{=}0.99$)---and in the
  nested probe its similarity is both lower and falls faster as tokens are
  appended ($0.68\!\to\!0.48$), tracking the changing meaning of the span rather
  than its prefix. Rather than keying on an entry point, the injected embedding
  reflects all constituents, an integrative, semantic composition.

\textbf{3. Neither tendency is inherited from the embedding tables.}
  Both base matrices give $r_K\!\approx\!1$ at every $K$, and growing-prefix real
  words are only weakly similar in the raw tables (e.g.\ \textit{success}:
  $\cos(H_2,H_4){=}0.34$ output, $0.14$ input---far below the encoder's $0.88$). Both compositional rules are
  therefore \emph{created} by the encoders, not read off the embedding geometry.

\begin{takeaway}
The two untied hyper-encoders converge to \emph{complementary} composition rules:
the output encoder is a prefix / entry-point detector, while the input encoder is
an integrator over the full span---and neither pattern exists in the base
embedding tables, so both are learned. A single tied or shared encoder is forced
to compromise between these opposing objectives, which is precisely why untying
is necessary.
\end{takeaway}
